\# Booking API — Система бронирования ресурсов (Cyber Loft)



\### О проекте

Учебный проект по разработке REST API для бронирования рабочих мест в коворкинге. 

Реализована логика предотвращения временных коллизий (нельзя занять один ресурс дважды на одно время).



\*\*Стек:\*\* Python 3.10, FastAPI, SQLAlchemy, PostgreSQL, Docker.



\### Функционал

\* \*\*Auth:\*\* Регистрация и JWT-авторизация.

\* \*\*Resources:\*\* Просмотр списка доступных зон (Cyber Loft, Meeting Room).

\* \*\*Bookings:\*\* Бронирование с проверкой пересечений по времени.

\* \*\*Roles:\*\* Разделение на обычных пользователей и админов.



\### Артефакты

\* \*\*ER-диаграмма:\*\* Находится в папке `docs/er-diagram.png`.

\* \*\*Схема API:\*\* Доступна через Swagger UI после запуска.
